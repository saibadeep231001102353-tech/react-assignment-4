# Assignment 4: Live Weather Metrics Dashboard

A responsive React weather dashboard built with Vite that fetches, formats, and displays real-time weather analytics, city forecasts, and comprehensive environmental metrics.

---

## 📌 Features & Highlights

- **City Search & Quick Select**: Search for any city worldwide with instant weather data retrieval.
- **Comprehensive Weather Metrics**:
  - Current temperature, Feels-like index, High/Low range
  - Humidity, Wind Speed, Atmospheric Pressure, Visibility
  - Sunrise and Sunset timings
- **Graceful Error Handling**: Error boundaries and user-friendly fallback screens when search queries fail or networks disconnect.
- **Visual Status Cues**: Dynamic weather condition icons and gradient backdrops reflecting day/night/cloudiness.
- **GitHub Pages Ready**: Automated GitHub Actions CI/CD workflow included.

---

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **Lucide React Icons**
- **Vanilla CSS (Custom design system)**

---

## ⚡ Getting Started Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
